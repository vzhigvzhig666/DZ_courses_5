# Каталог университетов

Консольное приложение на Kotlin: загружает список университетов выбранной страны из API, сохраняет его в MongoDB и ищет вузы по части названия.

## Требования

- JDK 21
- MongoDB на `mongodb://localhost:27017`

## Запуск

Откройте Gradle-проект в IntelliJ IDEA и запустите `Main.kt`. Введите название страны на английском, например `Russian Federation`, затем ищите университет по части названия. Для завершения введите `exit`.
